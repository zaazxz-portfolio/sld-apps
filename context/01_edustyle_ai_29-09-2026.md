# EduStyle AI - Development Context

**Tanggal:** 29 September 2026
**Proyek:** EduStyle AI (Aplikasi Pemetaan Gaya Belajar VAK berbasis AI)

Dokumen ini berfungsi sebagai catatan (context) dari segala fitur dan perbaikan yang telah diimplementasikan pada proyek ini. Informasi ini dapat digunakan oleh asisten AI lain untuk memahami arsitektur, status proyek, dan logika yang sudah dikembangkan sejauh ini.

---

## 1. Arsitektur & Lingkungan
- **Frontend:** HTML, Tailwind CSS (via CDN), jQuery, dan Lucide Icons.
- **Backend:** PHP Native (versi 8.x).
- **Database:** SQLite (file `db.sqlite` digunakan untuk menyimpan *settings* dan log riwayat).
- **Infrastruktur:** Docker (menggunakan `compose.yaml`).
  - *Host Networking:* Container PHP di-set agar dapat mengakses layanan lokal di *host* mesin (seperti 9Router API) menggunakan alias `host.docker.internal` (dikonfigurasi via `extra_hosts` di `compose.yaml`).

## 2. Integrasi 9Router AI
- Telah mengimplementasikan `/src/pages/api/analyze.php` sebagai *proxy* backend ke 9Router API.
- **Model:** Menggunakan kombinasi *fallback* otomatis (combo `coding`).
- **Flow:** Data nama, NISN, skor VAK dari sisi *client* diproses menjadi sebuah *prompt* yang meminta AI membuat profil diagnosis karakteristik, rekomendasi belajar mandiri, panduan guru, dsb. Format balasan diwajibkan dalam bentuk JSON.

## 3. UI/UX dan Logika JavaScript (`index.php`)
- **Multi-Step Form:** Memiliki empat tahap tampilan yang dikontrol via penambahan/penghapusan class `hidden`:
  1. `sectionForm`: Form pengisian data diri siswa.
  2. `sectionQuestionnaire`: Kuesioner dinamis yang di-render dari array (saat ini soal SMP/SMK digabung).
  3. `sectionLoading`: Animasi *spinner* saat menunggu *response* 9Router API.
  4. `sectionDashboard`: Tampilan hasil rapor gaya belajar.
- **Perbaikan Kritis JS:** 
  - Mencegah bentrok *template literal* JS (`${...}`) dengan *parser* PHP menggunakan *Nowdoc* (`<<<'HTML'`) dan pemisahan penggabungan string (concatenation) saat melempar nilai variabel PHP (`$hasApiKey`).
  - Angka jumlah soal (sebelumnya *hardcode* 12) telah dibuat dinamis menyesuaikan panjang *array* soal yang ada (`currentActiveQuestions.length`).

## 4. Format Cetak PDF (Print CSS)
- **Margin Bersih:** Menambahkan aturan CSS `@page { margin: 0; }` untuk menyembunyikan tulisan *header* dan *footer* bawaan browser (seperti URL halaman dan tanggal *browser*).
- **Padding Kustom:** Menambahkan padding khusus pada `#reportDocument` yaitu `1.5cm` (atas/bawah) dan `1cm` (kiri/kanan) agar konten terlihat elegan dan tidak terlalu menempel ke tepi kertas.
- **Page-Break Protection:** Menambahkan trik `display: inline-block !important; width: 100% !important;` berserta `break-inside: avoid;` pada kotak-kotak kartu *Rekomendasi* agar *engine* PDF *browser* tidak memotong kartu (clipping) tepat di tengah kalimat ketika berpindah halaman.
- **Grid Reset:** Menonaktifkan fitur *layouting* Grid CSS dan mengubahnya menjadi *Block* pada mode cetak (selain kolom tanda tangan) guna mencegah kekacauan render antar-halaman.

## 5. Fitur Lain-lain
- Tanggal pada dokumen pelaporan otomatis membaca tanggal sistem saat tombol *submit* ditekan.
- Nama penandatangan di kolom laporan langsung sinkron dengan nama yang diketikkan siswa.

---
**Catatan untuk AI selanjutnya:**
Jangan menggunakan *heredoc* (`<<<HTML`) untuk kode yang mengandung template string JS di dalam PHP, gunakan *nowdoc* (`<<<'HTML'`). Pastikan semua modifikasi UI di masa depan tetap memperhatikan stabilitas layout saat diprint (`@media print`).
